# v0.23.0 — 真实 AI 需求拆解与 DSH 派发、1:1 SVG 派生连线、统一设置中心与界面降噪

> v0.23.0 聚焦真实闭环可用性与工作台视觉降噪：将许愿澄清与目标拆解全面接入 DSH 宿主 LLM 与真实主从派发链路，重做派生树状图 1:1 Stage 坐标连线，清除卡片冗余徽标与硬编码模板芯片，并引入统一 `SettingsHubTab` 配置中心与遗留冗余剥离。

## 核心更新

- **真实 AI 需求澄清/拆解与 Strategy A 主从真实派发**：
  - 移除前端写死模板芯片（`WISH_STARTER_TEMPLATES`），澄清对话与任务拆解统一通过宿主 `invokeDshLlmJson`（`ctx.get('llm')`）实时推理生成；
  - 工作流派发与重跑直连 DSH 真实生命周期：优先经由 `subagents.startActivation` 派生子代理，必要时通过 `rootAgent.followup` 回落调度主代理执行。
- **派生树状图 1:1 Stage SVG 连线对齐**：
  - 移除易漂移/重叠的 `.rt-n8n-diamond-pin` 端口徽章，改用 `svg.rt-tree-edges-svg` 与缩放无关的 `measureBoxInStage` 测量坐标系，精确对齐主控与各 Wave 节点连线。
- **统一设置配置中心（`SettingsHubTab` + 宿主 `settings.section`）**：
  - 将团队并发与租约、8 角色提示词、存储探针、飞书通知与会话工作台隔离管理收口为单一 5 分区设置页，并接入 DSH 原生设置栏。
- **界面降噪与遗留冗余剥离**：
  - 彻底清除 `P0`–`P3` UI 优先级标签、装饰性 `#tags` 徽标与重复工作区提示条；
  - 剥离已废弃的历史兼容/迁移/发布脚本与 `concurrency.js` 等遗留模块，同步修复 Windows 下 `scripts/deploy-local.mjs` ESM 路径导入问题。
