# v0.23.2 — 后端模块化拆分、Wave 自动接力、写后越界审计与双端 22/22 测试全绿

> 聚焦代码可维护性、调度闭环稳定性与跨平台质量保障：拆分宿主桥接核心模块，新增 Wave 间自动接力、Worker 写盘越界审计与前后端版本不一致主动提醒，并实现 Windows / Linux 双端 22 个测试套件 100% 全绿。

## 核心更新

- **宿主桥接模块化拆分（`packages/redteam-ui/lib/`）**：
  - 将原先 8,500+ 行的 `index.js` 拆出 `llm-planner.js`（AI 澄清/拆解与 JSON 截断修复）与 `dsh-dispatch.js`（会话解包、子代理拉起与 Wave 推进），通过 `build.mjs` 自动打入单包产物与根目录 `lib/`。
- **Wave 间自动接力推进（`autoAdvanceWave`）**：
  - 在「设置 -> 集群并发与派发策略」新增 `autoAdvanceWave` 开关（默认关闭）；开启后，当 Wave $k$ 全部任务审批通过时，自动拉起 Wave $k+1$ 并发任务并同步通知 Captain。
- **Worker 写后分片越界审计（`auditWorkerScopeViolation`）**：
  - 提交 `worker_digest` 时自动核对 `files_touched` 与 `files_owned`，并在「协同与审批」审批卡中红色告警越界文件。
- **前后端版本不一致检测**：
  - 后端 `bootstrap` / `version` 透传 `hostVersion`，前端检测到与 `CLIENT_PLUGIN_VERSION` 不一致时顶部主动提示重启 `DSH NEXT`。
- **Windows 全量 22 个测试套件 100% 通过**：
  - 修复测试清理前 SQLite 句柄关闭、`pathToFileURL`、`path.sep` 与 Windows Git 索引权限校验，实现 Windows 本地与 Ubuntu CI 双端 `22/22` 绿灯。
