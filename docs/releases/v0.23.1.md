# v0.23.1 — 增强 AI 蓝图拆解 JSON 容错与截断自动修复

> 针对快速推理模型（如 `deepseek-v4.1-flash`）在生成多波次并发蓝图时可能输出 `<think>` 块、尾随逗号、未闭合代码块或触发 `maxTokens` 截断的问题，提升宿主侧 JSON 提取与自动修复鲁棒性。

## 修复内容

- **`decomposeWishWithAI` 输出上限提升至 `maxTokens: 8192`**：避免 4-Wave 多分片工程蓝图在生成途中被截断。
- **强化 `extractJsonFromLlmText` 与截断修复（`repairTruncatedJsonObject`）**：
  - 自动剥离 `<think>...</think>` 推理块与未闭合 Markdown 代码围栏；
  - 兼容对象/数组末尾多余逗号（`,}` / `,]`）；
  - 当模型输出在末尾字段处发生流式截断时，自动回退闭合未完成结构并保留已完整生成的 `goals` 分片条目；
  - 若仍无法解析，错误提示附加 `finishReason`、`len` 与响应首段预览以便定位。
